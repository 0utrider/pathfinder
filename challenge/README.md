# Challenge Point Calculator

Pathfinder Society (2e) scaling and difficulty. Set the party level range, the number of players and pregens, and the tool works out Challenge Points and which level range to play, with the relevant footnotes.

**Live version:** https://0utrider.github.io/pathfinder/challenge/index.html

Part of [Outrider's Pathfinder Projects](../README.md).

## Run it

Open `index.html` in a browser. No build step, no dependencies.

## Files

- `index.html`, `styles.css`, `script.js`
- `img/icon.webp` and the favicon set

The theme (light or dark) is stored in the browser and shared with the other tools on the same site.
