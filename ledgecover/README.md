# Ledge Cover Line of Sight

Pathfinder and Starfinder (2e) sightline calculator for a creature below a ledge and one on it. Enter the ledge height, each creature's size, height and distance, and the tool shows the cover level, the attack modifier and a diagram.

**Live version:** https://0utrider.github.io/pathfinder/ledgecover/index.html

Part of [Outrider's Pathfinder Projects](../README.md).

Assumes a simple vertical ledge (flat ground, flat top, one straight drop) with no other terrain in the way. Real terrain, creature reach, and GM adjudication all still apply.

## Run it

Open `index.html` in a browser. It is a single file with no build step and no dependencies.

The theme (light or dark) is stored in the browser and shared with the other tools on the same site.
